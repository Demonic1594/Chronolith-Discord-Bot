# ForgeTopGG functions — index

- [`$hasVoted`]($hasVoted.md) — Checks whether a user has voted a bot
- [`$monthlyVotes`]($monthlyVotes.md) — Gets total votes of the bot this month
- [`$postStatsError`]($postStatsError.md) — The error thrown while posting stats
- [`$postedServerCount`]($postedServerCount.md) — The server count that was posted
- [`$postedShardCount`]($postedShardCount.md) — The amount of shards that was posted
- [`$postedShardID`]($postedShardID.md) — The main shard id that was posted
- [`$totalVotes`]($totalVotes.md) — Gets total votes of the bot
- [`$voteBotID`]($voteBotID.md) — Returns the bot that was voted
- [`$voteGuildID`]($voteGuildID.md) — Returns the guild that was voted
- [`$voteIsWeekend`]($voteIsWeekend.md) — Returns whether the vote was during weekend
- [`$voteQuery`]($voteQuery.md) — Returns the query params used for the guild
- [`$voteType`]($voteType.md) — Returns the type of the vote (upvoted | test)
- [`$voteUserID`]($voteUserID.md) — Returns the user who voted the bot
