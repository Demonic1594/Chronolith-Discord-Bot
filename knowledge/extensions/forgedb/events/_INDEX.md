# ForgeDB events — index

- [`connect`](connect.md) — This event is triggered when ForgeDB is connected with ForgeScript
- [`variableCreate`](variableCreate.md) — This event is triggered when a new variable gets created.
- [`variableDelete`](variableDelete.md) — This event is triggered when a variable gets deleted.
- [`variableUpdate`](variableUpdate.md) — This event is triggered when a variable gets updated.
