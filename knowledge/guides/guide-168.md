# $userCount guide

> Community guide for `$userCount` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-168)

`$userCount` returns the total number of users **across all servers** the bot is in.

Example:
```fs
$userCount
```

Output might be:  
`45231`

Useful for statistics, tracking bot reach, or leaderboard features.
