# $randomUUID guide

> Community guide for `$randomUUID` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-149)

`$randomUUID` generates a **random UUID** (Universally Unique Identifier).

Example:
```fs
$randomUUID
```

Output:  
`3fa85f64-5717-4562-b3fc-2c963f66afa6`

Useful for unique IDs in databases, tracking, or any situation where a unique string is needed.
