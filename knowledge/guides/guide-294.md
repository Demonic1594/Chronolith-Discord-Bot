# Working with Extensions

> Community guide for `None` (none) — package **BotForge Developer API**. Approved 2026-07-25. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-294)

The extensions endpoint `/v1/extensions` allows you to fetch details about verified BotForge packages and sub-resources dynamically. This serves as the registry access point for integrations, package managers, and documentation tools.

### 1. Listing All Extensions
Retrieve a complete list of all verified official and community extensions. You can filter the returned list using query parameters.

**Endpoint:**
```http
GET /v1/extensions HTTP/1.1
Host: api.botforge.org
```

**Query Parameters:**
* `official` (Optional, Integer): Filter extensions by official status (`1` for official, `0` for community).
* `verified` (Optional, Integer): Filter extensions by verification status (`1` for verified, `0` for unverified).

<div class="alert-box alert-warning my-4">
  <div class="alert-title font-semibold mb-1">WARNING</div>
  <div>Filtering by unverified extensions (verified=0) or requesting them individually requires a private API key. Public and anonymous requests attempting to access unverified extensions will receive a 403 Forbidden error. If verified is not specified, unverified extensions are hidden by default for non-private keys.</div>
</div>

**Example Request:**
```http
GET /v1/extensions?official=1 HTTP/1.1
Host: api.botforge.org
```

### 2. Fetching a Single Extension
To fetch the metadata details for a specific extension, provide its name in the `name` parameter.

**Endpoint:**
```http
GET /v1/extensions?name={extensionName} HTTP/1.1
Host: api.botforge.org
```

**Example Request:**
```http
GET /v1/extensions?name=ForgeScript HTTP/1.1
Host: api.botforge.org
```

### 3. Querying Extension Sub-resources
You can query specific sub-resources (`functions`, `events`, or `enums`) parsed for a specific extension. Provide the extension `name` and the desired `resource` type.

**Endpoint:**
```http
GET /v1/extensions?name={extensionName}&resource={resourceType} HTTP/1.1
Host: api.botforge.org
```

**Query Parameters:**
* `name` (Required, String): The case-insensitive name of the target extension.
* `resource` (Required, String): The sub-resource type. Supported options: `functions`, `events`, `enums`.
* `search` (Optional, String): Filter the returned items by matching search queries against their name or description.
* `item_name` (Optional, String): Fetch details for a specific single item by name (e.g., a single function or event name).

**Example Request (Searching for JSON-related functions in ForgeScript):**
```http
GET /v1/extensions?name=ForgeScript&resource=functions&search=json HTTP/1.1
Host: api.botforge.org
```
