# $min guide

> Community guide for `$min` (function) — package **ForgeScript**. Approved 2025-06-21. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-101)

``$min[...]`` returns the smallest number of the ones given as parameters.
For example, if you do ``$min[1;2;3;5;6;7;8;9;10]``, you will receive "**1**" as output.

It's quite simple to understand, ``$min[3;7;4;8;9;2;33;53535]`` will return "**2**", because it's the smallest number on the list.

If you want to check what's the biggest number instead of the smallest, refer to the [$max](https://docs.botforge.org/function/$max) function, which works the same way but with the biggest number.
