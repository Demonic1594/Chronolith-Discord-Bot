# $isValidColor[code]

Checks if the given code is a valid color (hex, rgb, hsl, etc).  
Returns `true` or `false`.

**Example**
```fs
$isValidColor[#ff0000] $c[ Returns true ]
$isValidColor[notacolor] $c[ Returns false ]
```
