# $reverseText[]

Reverses the given text.

### Examples
```fs
$reverseText[ForgeScript] $c[ Returns tpircSegroF ]

$reverseText[12345] $c[ Returns 54321 ]

$sendMessage[$channelID;$reverseText[Hello!]] $c[ Sends !olleH ]
```
