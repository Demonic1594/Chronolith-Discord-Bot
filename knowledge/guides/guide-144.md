# $toSnakeCase guide

> Community guide for `$toSnakeCase` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-144)

`$toSnakeCase[text]` converts a string to **snake_case**, all lowercase with words separated by underscores.

Example:
```fs
$toSnakeCase[Hello World Example]
```

Output:  
`hello_world_example`

Useful for file names, variables, or any format that requires snake_case.
