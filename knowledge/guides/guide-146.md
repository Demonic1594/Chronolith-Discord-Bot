# $toTitleCase guide

> Community guide for `$toTitleCase` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-146)

`$toTitleCase[text]` converts a string so that the first letter of each word is **capitalized**.

Example:
```fs
$toTitleCase[hello world example]
```

Output:  
`Hello World Example`

Great for formatting titles, headers, or any text that needs proper capitalization.
