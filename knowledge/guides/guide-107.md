# $pi guide

> Community guide for `$pi` (function) — package **ForgeScript**. Approved 2025-06-21. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-107)

`$pi` returns the mathematical constant π (pi), which is **3.141592653589793**.

Example usage:  
`$pi` → **3.141592653589793**

You can use it in math expressions too:  
`$math[$pi*2]` → 3.141592653589793 * 2 = **6.283185307179586**
