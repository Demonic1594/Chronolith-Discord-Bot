# $toCamelCase guide

> Community guide for `$toCamelCase` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-143)

`$toCamelCase[text]` converts a string to **camelCase** formatting, the first word is lowercase and each following word starts with a capital letter, with no spaces.

Example:
```fs
$toCamelCase[hello world example]
```

Output:  
`helloWorldExample`

Useful for variable names, identifiers, or coding conventions that use camelCase.
