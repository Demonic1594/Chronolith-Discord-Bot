# $authorID guide

> Community guide for `$authorID` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-116)

This is a very commonly used function and as the name suggests, **`$authorID`** (Alias: `$userID`) returns the ID of the author (user) who executed the current command, interaction or context in general.

Example Output: `729343563401265193`

The output can be used in various other functions that expect a user ID as an argument.
