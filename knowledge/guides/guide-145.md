# $toLowerCase guide

> Community guide for `$toLowerCase` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-145)

`$toLowerCase[text]` converts all letters in the given text to **lowercase**.

Example:
```fs
$toLowerCase[HeLLo WoRLD!]
```

Output:  
`hello world!`

Useful for case-insensitive comparisons, standardizing input, or formatting text.
