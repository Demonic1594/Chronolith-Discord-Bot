# $repeat[]

Repeats the given text a specified number of times.

## Examples
```fs
$repeat[ha;3] $c[ Returns hahaha ]

$repeat[⭐;5] $c[ Returns ⭐⭐⭐⭐⭐ ]

$sendMessage[$channelID;$repeat[Hello! ;2]] $c[ Sends "Hello! Hello! " ]
```
