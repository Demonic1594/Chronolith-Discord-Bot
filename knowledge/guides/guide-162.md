# $randomUserID guide

> Community guide for `$randomUserID` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-162)

`$randomUserID` returns a **random Discord user ID**.

Example:
```fs
$randomUserID
```

Output might look like:  
`1122842723867705356`

Useful for testing, random user selection, or unique ID generation.
