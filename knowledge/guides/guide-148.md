# $toUpperCase guide

> Community guide for `$toUpperCase` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-148)

`$toUpperCase[text]` converts all letters in the given text to **uppercase**.

Example:
```fs
$toUpperCase[hello world!]
```

Output:  
`HELLO WORLD!`

Useful for shouting text, emphasis, or formatting consistency.
