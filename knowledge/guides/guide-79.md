# $botCustomInvite guide

> Community guide for `$botCustomInvite` (function) — package **ForgeScript**. Approved 2025-06-15. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-79)

**$botCustomInvite** returns the Custom URL you setup on [Discord's Developer Portal](https://discord.com/developers/applications), on the "Installation" tab.
