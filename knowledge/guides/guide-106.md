# $pi guide

> Community guide for `$pi` (function) — package **ForgeScript**. Approved 2025-06-21. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-106)

As the description already suggests, **`$pi`** returns the constant PI number. This can be useful in mathematical expressions without having to manually insert the full number.

### Output
```
3.141592653589793
```
