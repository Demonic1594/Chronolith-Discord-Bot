# $botID guide

> Community guide for `$botID` (function) — package **ForgeScript**. Approved 2025-06-15. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-75)

I don’t think this requires a guide; **$botID** returns your Discord’s Bot ID, which is a snowflake typically between 17 and 19 characters long. Example output: `1147478356657446982`

You can then use this ID in any other function you want, such as `$username[$botID]` to return your Bot’s username.
