# $ping guide

> Community guide for `$ping` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-130)

`$ping` is a self-explanatory function that returns the bot’s current ping in milliseconds.

It shows how quickly the bot is responding to Discord, useful for checking performance or connection issues.

Example:
```fs
Pong! $pingms
```

This might return something like:
```
Pong! 45ms
```

Aliases:
- `$clientPing`
- `$botPing`
