> Community guide for `$randomColor` (function) — package **ForgeColor**. Approved 2025-09-01. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-227)

# $randomColor[output format?]

Generates a random color.  
Default format is HEX.

**Example**
```fs
$randomColor $c[ Returns #3fa9f5 ]
$randomColor[rgb] $c[ Returns rgb(63,169,245) ]
```
