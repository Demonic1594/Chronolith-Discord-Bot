# $randomText guide

> Community guide for `$randomText` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-150)

`$randomText[option1;option2;option3;...]` picks a **random value** from the list of provided options.

Example:
```fs
$randomText[ok;ye;hi]
```

This will randomly return one of:  
`ok`  
`ye`  
`hi`

Useful for random responses, choices, or fun outputs.
