# $messageID guide

> Community guide for `$messageID` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-122)

This is a very commonly used function and as the name suggests, **`$messageID`** returns the ID of the current message, this means the message that triggered the command, interaction or context in general.

Example Output: `1386123651115389018`

The output can be used in various other functions that expect a message ID as an argument.

> ⚠️ `$messageID` does **not** return the ID of the bot's response!
