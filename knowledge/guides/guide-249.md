# $max guide

> Community guide for `$max` (function) — package **ForgeScript**. Approved 2025-10-12. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-249)

`$max[...]` returns the biggest number of the ones given as parameters.
For example, if you do `$max[1;2;3;5;6;7;8;9;10]`, you will receive "**10**" as output.

It's quite simple to understand, `$max[3;7;4;8;9;2;33;53535]` will return "**53535**", because it's the biggest number on the list.

If you want to check what's the smallest number instead of the biggest, refer to the [`$min[]`](https://docs.botforge.org/function/$min) function, which works the same way but with the smallest number.
