# $log guide

> Community guide for `$log` (function) — package **ForgeScript**. Approved 2025-09-03. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-235)

The **`$log[]`** function logs the provided text to your client's console. This can be useful for basic logging messages or debugging purposes.

### Example
```fs
$log[Logged to the console!]
```
