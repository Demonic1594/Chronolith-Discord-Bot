# $stop guide

> Community guide for `$stop` (function) — package **ForgeScript**. Approved 2025-06-27. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-189)

# 📒 Overview
Want to stop your code when it needs to? Use ```$stop``` anywhere in your code to stop code from running after the function.

# 🔍 Deep Explanation
This function works without brackets, it stops your code from running after it's been called. When you want to stop when it's needed, you will need to call ```$stop``` This function works in different scenarios, from getting your code to stop automatically after errors, to specifically stopping the code for banned users. It has a wide variety of different uses, and it's up to you to decide what to do with it.
