# $toKebabCase guide

> Community guide for `$toKebabCase` (function) — package **ForgeScript**. Approved 2025-06-22. [View on docs.botforge.org](https://docs.botforge.org/guide/guide-141)

`$toKebabCase[text]` converts a string to **kebab-case**, that means all lowercase with words separated by hyphens.

Despite the name, it **does** turn your text into kebab-case (not something else).

Example:
```fs
$toKebabCase[Hello World Example]
```

Output:
`hello-world-example`

Useful for URLs, identifiers, or any place kebab-case formatting is needed.
