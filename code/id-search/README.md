# Advanced ID Search Command
> **Commands** -
- `id-search <ID>` - Search for an ID (prefix)
- `/id-search id:<ID>` - Search for an ID (slash)

> **Features** -
- Check for an ID, whether it's an emoji, channel, user or role
- Organised embeds, different interactions for permissions, roles and members
